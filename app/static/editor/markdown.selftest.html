markdown.js selftest

Drives serializeMarkdown() from ./markdown.js over the editor's HTML vocabulary. Each case's HTML is set via innerHTML -- the same browser parser editor.setHTML() uses -- and the result is compared with the expected markdown. The HTML samples and expected markdown mirror markdown::to_html's test table in crates/av-vault/src/markdown.rs, so a case here plus its Rust counterpart together assert the cross-language round trip to_html(serializeMarkdown(html)) == html. The cases are in markdown.selftest.js; build.rs bundles them into a copy of this page in its OUT_DIR, which opens from disk, no server needed.
